Frequently asked questions

Can't find your answer? Report a problem or ask a question on GitHub.

Is it really free?

Yes. There is no trial, watermark, account or paid version. It is open source under the MIT License.

Is it safe? Why does Windows say "Windows protected your PC"?

Windows SmartScreen warns about apps it doesn't recognize, and about files that aren't code-signed. This app isn't code-signed, so you will probably see the warning the first time. To continue, click More info, then Run anyway.

The source code is public on GitHub, the downloads are built there by an automated workflow, and each release lists SHA-256 checksums so you can check your download.

Are my videos uploaded anywhere?

No. Everything runs on your computer. The app has no accounts, ads or tracking, and it doesn't send your files anywhere. It only goes online for an optional once-a-day check for a newer version (you can turn it off) and, if you use automatic captions, a one-time download of the speech model from Hugging Face. Report a problem opens your web browser on GitHub.

Do I need to install anything else, like FFmpeg?

No. The FFmpeg engine and everything else the app needs are built in, in both the installer and the portable version.

Installer or portable version?

The installer installs just for you (no administrator rights needed, or choose all users), adds a Start menu entry, optionally a desktop shortcut, and an "Open with Free Video Editor" entry for video and audio files. It doesn't change which app opens your files by default. Remove it in Windows Settings → Apps.

The portable version is a single file, FreeVideoEditor.exe. Double-click it; nothing is installed.

Will it change or overwrite my original videos?

Never. Results are saved as new files next to the originals, like name (phone).mp4, and if a name is already taken the new file gets a number, like file (1).mp3. You can also pick a different folder in the Save to section.

Which video formats work?

MP4, MOV, MKV, AVI, WEBM, M4V and other common video formats. It also opens audio files (MP3, M4A, AAC, WAV, FLAC, OGG, OPUS) so you can trim, cut or save them as MP3. Videos are exported as MP4, and audio as MP3.

My video won't play on my phone. Can this fix it?

Often, yes. Game recordings and screen captures commonly have a frame rate that keeps changing, which some phones refuse to play. Choose the Play on phone (keeps the whole picture) preset and click Export. See the step-by-step guide.

Why does stabilizing take so long?

Stabilizing runs while exporting, in two passes: it first studies how the camera moved and then smooths it. That takes longer than a normal export, and the preview doesn't show the effect.

Is the app available in Arabic?

Yes, from version 3.0. The app has a full Arabic interface that runs right to left, and it follows Windows automatically when Windows is set to Arabic. Change it at any time under View → Language (English, العربية or Same as Windows); the new language is used after the app restarts. The timeline and the video player stay left to right, because time runs that way in a video editor. The website is also available in Arabic.

Can I use it from the command line?

Yes. When you run it from source, you can pass files to convert them without opening the window. The options are listed in the README.

How do I report a problem or suggest something?

Open an issue on GitHub. In the app, Help → Report a problem… can take you there, and if an export failed, the Details button shows what went wrong. The app also writes a log file that you can attach; Help → Open the log folder opens it.

What licenses does it use?

Free Video Editor is under the MIT License. The Windows app bundles FFmpeg (GPLv3) and Qt for Python (LGPLv3); the notices are in the licenses folder.
