====================================================================

unmodified, as a separate library inside the application (in the installed version they are separate files
in the application folder; the portable single-file exe unpacks the same files to a temporary folder when
it starts). The versions are those of the Windows builds made from requirements-build.lock.

PyAV is NOT included
--------------------
faster-whisper depends on the PyAV package ("av"), which ships FFmpeg libraries together with GPL codec
libraries (x264, x265). Free Video Editor does not need it: the sound is extracted with the separate ffmpeg.exe
described in FFMPEG-NOTICE.txt and handed to the speech engine as numbers. So the Windows builds leave PyAV and
its libraries out and contain only a small stand-in module that is never used. (The stand-in is the file
av\__init__.py in the application folder.)
