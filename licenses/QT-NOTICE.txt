Qt and PySide6 in Free Video Editor
===================================

Free Video Editor's window, controls and video player are built with Qt for Python (PySide6) 6.12.0, which
uses the Qt framework 6.12.0 (https://www.qt.io/qt-for-python). The Windows builds include the Qt libraries
UNMODIFIED, exactly as published on PyPI (packages PySide6-Essentials, PySide6-Addons and shiboken6, all 6.12.0).

Replacing the Qt libraries (relinking)
--------------------------------------
LGPL lets you run this program with your own build of Qt. You can do that in two ways:

  1. In the installed version (made by the setup program), Qt is not merged into the program: every Qt
     library is a separate .dll or .pyd file in the application folder (inside the "_internal" folder next
     to "Free Video Editor.exe": Qt6*.dll, PySide6\*.pyd, shiboken6\*.dll). Replace them with compatible
     builds of the same Qt for Python version and start the program again.

  2. Free Video Editor is free software under the MIT License and its complete source code is at
     https://github.com/Ahmed41022/free-video-editor . You can rebuild the program with a different
     version of PySide6 yourself:
         pip install -r requirements-build.txt     (then install the PySide6 you want in place of the pinned one)
         python build_exe.py --onedir              (folder build, as the installer uses)
         python build_exe.py                       (single-file exe)
     The program is plain Python code that uses only the public PySide6 API, so it needs no other changes.

The portable single-file "FreeVideoEditor.exe" contains the same Qt files packed into one archive; it unpacks
them to a temporary folder when it starts. To use your own Qt libraries, use the installed version or rebuild
the program as described in step 2.
