FFmpeg in Free Video Editor
===========================

Bundled FFmpeg version: 7.1-essentials_build-www.gyan.dev

Free Video Editor includes an UNMODIFIED copy of FFmpeg (ffmpeg.exe), which it runs as a separate program
to read and convert media files. FFmpeg is a trademark of Fabrice Bellard, originator of the FFmpeg project.

  Built by:       Gyan Doshi (gyan.dev), with gcc 14.2.0 (MSYS2); static 64-bit Windows build, "essentials" edition

  FFmpeg commit:  b08d7969c5 (https://github.com/FFmpeg/FFmpeg/commit/b08d7969c5), release 7.1

License: GNU General Public License, version 3 (GPLv3). The build is configured with --enable-gpl
--enable-version3 because it includes GPL libraries (below), so the whole ffmpeg.exe is GPLv3.

LGPL-2.1.txt are included as well).

  --enable-dxva2 --enable-d3d11va --enable-d3d12va --enable-ffnvcodec --enable-libvpl --enable-nvdec

Written offer
-------------
For three years from the date you received this program, the author will provide the complete corresponding
source code for the FFmpeg build above and for the GPL and LGPL libraries in it, on request. Ask by opening an
issue at

    https://github.com/Ahmed41022/free-video-editor/issues

(title it "FFmpeg source request"). The source is provided free of charge, apart from the cost of any
physical medium you ask for.

Free Video Editor's own source code is a separate work, licensed under the MIT License (see LICENSE). It
only starts ffmpeg.exe as a separate program and talks to it through command-line arguments; it does not link
to FFmpeg's libraries.
